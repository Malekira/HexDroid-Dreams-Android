# HexDroid Dreams 1.0.14

Actualiza las fotos publicadas por la web: decodifica el campo de foto de GECOS, normaliza los dos dominios oficiales y respeta las actualizaciones y retiradas de METADATA. Las solicitudes oficiales llevan una versión de caché; abrir o actualizar el visor fuerza una descarga nueva. Una respuesta anterior no puede reemplazar una foto invalidada. Se mantienen los límites de tamaño, HTTPS y las restricciones de descarga con proxy.

El menú del chat incluye «Visor de logs». Permite consultar el archivo privado y abrir documentos TXT/LOG con el selector de Android. Busca todas las palabras introducidas sin distinguir mayúsculas, resalta coincidencias y pagina cien líneas. Se conservan las opciones existentes de exportación, restauración y borrado con confirmación. Los documentos externos se leen sin modificarlos.

Mantiene las pestañas superiores compactas, Tab y el árbol de salas/privados de 1.0.13. Versión 1.0.14, código 53.

Pruebas nuevas: formato web, prioridad y retirada de fotos, versiones de caché, búsqueda y paginación, cierre de archivos, carrera entre descargas y búsqueda en Compose. La compilación CI ejecuta además las pruebas anteriores.
